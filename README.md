# 发育全流程规划器

单文件、中文界面的离线发育规划工具。根据枪械伤害、射速、普通进度倍率和回合时间，比较购买顺序，规划更早完成所选构筑的路线。

## 使用

下载本仓库（Code → Download ZIP），解压后用 Edge 或 Chrome 打开 `index.html`。无需安装依赖、启动服务或联网计算。

1. 在“枪械与规则配置”中填写枪械数据与适用加成，选择伤害芯片或过载方案。
2. 填写普通进度倍率、回合结算时间与剩余结算次数。
3. 主页先生成快速规划；可点击“多线程穷举最优顺序”继续求解。
4. 按路线完成项目并勾选，右侧可单独计算射速阈值。

## 功能

- 每把枪独立配置伤害、射击间隔、暴击及专项加成。
- 32 tick 射速计算与提档所需加成。
- 6×6 芯片构筑，旋转摆放及成本计算；伤害芯片与过载互斥。
- 指挥妖精的回合奖励、基因震爆器与沃陶姆的伤害积累及持续时间计算。
- 多线程购买顺序搜索；可选自动、1、2、4、8线程，停止时保留当前最快路线。
- 浏览器本地保存、完整JSON备份导入导出，以及支持浏览器中的授权文件自动保存。

## 保存数据

配置和搜索结果保存在当前浏览器本地，不上传到服务器。清理网站数据可能删除本地记录，请通过“导出完整备份”保存JSON文件。

支持文件授权接口的浏览器可以选择磁盘文件并自动保存。刷新或重开后，通过“打开文件并自动保存”重新连接。导入备份会替换当前枪械和共享规则；搜索结果按配置匹配恢复。

备份包含枪械、规则、完成勾选与已保存搜索结果，不包含未完成搜索的完整执行栈。不要将个人备份提交到本公开仓库。

## 计算范围

优化目标是固定当前枪械与芯片构筑、在当前模型和购买策略下尽早完成核心构筑。只有完整搜索结束才标记“当前候选及购买策略内最优”。

模型采用持续输出及期望伤害计算，尚不覆盖所有芯片布局、逐发换弹停火、主动延迟购买或整局总收益。大型构筑可能需要长时间搜索。页面“计算范围与未确定参数”中列出了具体假设。

游戏机制与数值可能随版本改变，请以实际测试为准。配置与结果以本地文件备份为准。
